📚 Student Performance SQL Tracker

📌 About This Project

This is one of my SQL projects, where I worked with student academic data to understand how SQL can be used to analyze and retrieve useful information from a database.

I used a dataset containing information about 200 students, including their marks, attendance, gender, and academic performance.

My main goal was to practice SQL queries while exploring student performance, identifying top-performing students, and understanding how attendance and marks can be analyzed.

Through this project, I gained hands-on experience in writing SQL queries and working with student data.

🛠️ Tools Used

- SQL
- SQLite Online Editor
- SQL Queries and Joins
- Aggregate Functions

📊 Dataset Description

The dataset contains records of 200 students with the following information:

- Student ID
- Student Name
- Gender
- Class
- Attendance Percentage
- Subject Marks (Math, Science, English, Social, and Computer)
- Total Marks
- Average Marks

 🔍 What I Analyzed

1. Student Performance Analysis
I used SQL queries to identify students with the highest total marks and the top performers in individual subjects.

2. Subject-Wise Performance
I calculated the average and minimum marks for different subjects to understand overall academic performance.

3. Attendance Analysis
I identified students with attendance below 75% and grouped students into different attendance ranges.

4. Student Pass and Fail Analysis
I used conditional queries to identify students who scored below 35 marks in any subject.

5. Gender-Wise Performance
I compared average marks by gender using SQL aggregate functions and GROUP BY.

6. SQL Joins

I practiced INNER JOIN and LEFT JOIN to retrieve student information from related tables.
I also combined joins with WHERE, ORDER BY, and GROUP BY to analyze student marks.
